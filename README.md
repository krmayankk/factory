# factory

Idea to running system, from a phone, with guardrails on every dollar and every credential.

Capture an idea in a Claude session from anywhere; it becomes a reviewed `ideas/*.md`
PR; merging it creates a new repository from a template that ships with its gates,
its least-privilege cloud role and its spending limits already in place. Agents build;
CI proves; a human approves anything that spends money.

Designed and built by **Mayank Kumar** ([@krmayankk](https://github.com/krmayankk)).
